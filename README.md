# Vehicle Classification System - Auto Tech

A web-based application for vehicle classification and analysis using modern web technologies.

## 📋 Overview

This project provides an intuitive interface for classifying vehicles and accessing automotive information. Built with responsive design principles to ensure compatibility across all devices.

## 🛠️ Technology Stack

| Technology | Usage | Percentage |
|-----------|-------|-----------|
| **HTML5** | Structure & Markup | 97.7% |
| **CSS3** | Styling & Responsive Design | 2.2% |
| **JavaScript** | Interactivity & Client-side Logic | 0.1% |

## 🚀 Features

- Clean and intuitive user interface
- Vehicle classification system
- Responsive design for mobile and desktop
- Real-time vehicle information processing

## 📂 Project Structure

```
Vehicle-classification-Auto-Tech-/
├── index.html          # Main application entry point
├── styles/             # CSS styling
├── scripts/            # JavaScript functionality
└── assets/             # Images and resources
```

## 🔧 Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/SujanSp27/Vehicle-classification-Auto-Tech-.git
```

2. Navigate to the project directory:
```bash
cd Vehicle-classification-Auto-Tech-
```

3. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

4. Access the application at `http://localhost:8000`
